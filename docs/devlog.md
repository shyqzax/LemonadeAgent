# Devlog

## 2026-10-01 — день 1: старт

- Утвердили план (`docs/PLAN.md`) и создали проект.
- На ПК уже есть adb/fastboot (platform-tools 37.0.0 из Android SDK), Python 3.14 и git. scrcpy пока не установлен.
- Сверились с документацией DeepSeek. `deepseek-flash` (V4.1-Flash) принимает картинки как `image_url` с `data:image/jpeg;base64,...`.
  Про function calling вместе с картинками там ничего не сказано. Поэтому мозг отвечает одним JSON-действием в тексте.
  В этом же формате потом сможет отвечать и локальная модель.
- Написан каркас агента этапа 1: слой устройства (adb / su), восприятие (дерево UI + скриншот с номерами элементов),
  мозг на DeepSeek, фильтр опасных действий, главный цикл с логами и CLI. Офлайн-тесты проходят.
- Известное ограничение: `adb shell input text` не вводит кириллицу. Для русского текста позже поставим ADBKeyBoard.
- Телефон подключён: **LE2111** (индийская версия, не операторская), OxygenOS `LE2111_14.0.0.1902(EX01)`, Android 14,
  12 ГБ ОЗУ, 221 ГБ памяти. Загрузчик пока заблокирован, «Разблокировка OEM» включена — к этапу 2 готово.
- Python-пакеты стоят в `.venv`. scrcpy v4.1 скачан с GitHub (SHA256 сверен) в `tools/scrcpy`, трансляция экрана работает.
- Грабли OxygenOS: adb не может менять системные настройки (`WRITE_SETTINGS` / `WRITE_SECURE_SETTINGS`),
  поэтому у scrcpy не работают `--show-touches` и `--stay-awake`. Лечится пунктом «Отключить мониторинг разрешений»
  в настройках разработчика. На LineageOS с root этой проблемы не будет.
- Первый живой прогон восприятия: домашний экран → 21 элемент, скриншот с номерами выглядит чисто.
  Скриншот и дерево UI снимаются по ~2,4 с каждый, теперь параллельно: `observe()` занимает 2,5 с вместо 4,7 с.

## 2026-10-01 — ночь: этап 2, LineageOS 23.2 + root

Процедура — строго по официальной вики, конспект в `docs/stage2-lineageos.md`.

| | |
|---|---|
| Было | OxygenOS `LE2111_14.0.0.1902(EX01)`, Android 14, загрузчик заблокирован |
| Стало | **LineageOS 23.2** (`23.2-20260928-NIGHTLY-lemonade`), **Android 16**, патч 2026-09-01 |
| Google | MindTheGapps 16.0.0 arm64 (20260915): Play Маркет и GMS на месте |
| Root | **Magisk 30.7**, `su -c id` → `uid=0(root) context=u:r:magisk:s0` |
| Файлы | все с download.lineageos.org / GitHub, SHA256 сверены до прошивки |

Грабли по порядку:
1. **Драйвер fastboot.** В fastboot телефон виден как `USB\VID_18D1&PID_D00D`, а официального Google USB Driver r13
   этот PID нет в `android_winusb.inf`. Ставили вручную: Диспетчер устройств → Обновить драйвер → Установить с диска →
   Android Bootloader Interface. Заодно выяснили, что в поле «Искать драйверы в следующем месте» путь вставлять бесполезно.
2. **Кнопки не пускали в fastboot.** Громкость+ + Громкость− + Питание держали по 30–60 с — телефон грузился как обычно.
   Обошли через `adb reboot bootloader`: после разблокировки в свежем OxygenOS отладка по USB уже включена,
   осталось разрешить доступ ПК (первое разрешение почему-то не сработало, помог повтор).
3. **Git Bash подменяет пути.** `adb push boot.img /sdcard/Download/` молча ушёл «в никуда»: MSYS превратил
   `/sdcard/...` в `C:/Program Files/Git/sdcard/...`. Для команд adb с путями на телефоне — `MSYS_NO_PATHCONV=1`.
4. **Play Protect** на Android 16 отклонил установку ADBKeyBoard по USB (`INSTALL_FAILED_VERIFICATION_FAILURE`).
   Повторили, пока владелец смотрел на экран, — прошло. Magisk ставился без вопросов.
5. **KernelSU-Next не подходит:** ядро 5.4 (`5.4.302-qgki`), а ему нужен GKI 5.10+. Root — Magisk, патч `boot.img`.
6. Модель теперь называет себя `LE2110`: единая сборка LineageOS для всех вариантов OnePlus 9. Это нормально.
