# 🍋 Lemonade Agent

ИИ-агент, который сам управляет Android-телефоном: смотрит на экран, решает, что нажать, и нажимает.
Назван по кодовому имени OnePlus 9 — **lemonade**. Это исследовательский проект. В нём есть бенчмарк,
обучение агента на своём опыте, маленькая модель прямо на телефоне и проверка атак через экран.

> **Статус:** этап 1. Агент управляет телефоном с ПК по USB через adb, решения принимает DeepSeek (`deepseek-flash`).

## Как это работает

```
задача → [дерево UI + скриншот с номерами] → DeepSeek → JSON-действие → проверка безопасности → adb input → …
```

- **Восприятие** (`agent/perception.py`): `uiautomator dump` превращается в короткий список `[5] Switch "Dark theme" {on}`.
  На скриншоте те же элементы обведены и подписаны номерами (Set-of-Mark).
- **Мозг** (`agent/brain.py`): на каждом шаге модель возвращает одно действие: `tap`, `type`, `swipe`, `open_app`, `back`, `done`…
- **Безопасность** (`agent/safety.py`): нажатия вроде «Отправить», «Оплатить», «Удалить» подтверждает человек.
  Банковские приложения и кошельки агенту недоступны.
- **Устройство** (`agent/device.py`): у `AdbDevice` (с ПК) и `RootDevice` (на телефоне через `su`) одинаковый интерфейс.
- **Логи** (`logs/`): каждый шаг сохраняется со скриншотом и ответом модели. Это одновременно материал для видео и датасет для дообучения.

## Быстрый старт

1. На телефоне включи режим разработчика и «Отладку по USB», подключи кабель и разреши доступ.
2. Установи зависимости и настрой ключ:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   ```
   В `.env` вставь свой ключ DeepSeek.
3. Проверь окружение: `python scripts/doctor.py`
4. Запусти агента: `python -m interfaces.cli "включи тёмную тему"`

Режимы восприятия: `--mode both` (по умолчанию), `--mode tree`, `--mode screen`.
