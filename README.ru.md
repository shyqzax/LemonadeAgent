# 🍋 Lemonade Agent

**ИИ-агент, который сам управляет настоящим Android-телефоном.** Смотрит на экран, решает, что нажать, и нажимает.
Назван по кодовому имени OnePlus 9 — *lemonade*.

Это открытый исследовательский проект. План такой: собрать агента для телефона, измерить его на бенчмарке, научить
учиться на своём опыте, дистиллировать в маленькую модель, которая работает **офлайн прямо на телефоне**,
и проверить, как он держится против промпт-инъекций с экрана.

🇬🇧 [English version](README.md)

> **Статус:** этап 4 пройден. Агент живёт в самом телефоне (Termux + root, LineageOS 23.2 / Android 16),
> берёт задачи из Telegram-бота и учится на опыте: на бенчмарке из 30 задач память-навыки сокращают вызовы модели
> на 30%. Мозг пока DeepSeek `deepseek-flash`; маленькая модель на телефоне — этап 5.
> Ход работы — в [devlog](docs/devlog.md).

## Как это работает

```
задача ──► смотрит ──► решает ──► проверка ──► действует ──► … до «готово»
             │            │        безопасности      │
       дерево UI +    DeepSeek:   опасные нажатия   adb input
       скриншот       одно JSON-  подтверждает      tap / text / swipe
       с номерами     действие    человек
```

Вот что модель видит на экране «Настройки → Экран и яркость»:

```
Приложение: com.android.settings
[4] LinearLayout "Светлый режим" {click}
[5] RadioButton id=rb_light_button {off}
[6] LinearLayout "Режим затемнения" {click}
[7] RadioButton id=rb_dark_button {on}
```

Вместе со списком модель получает скриншот, на котором те же элементы обведены и подписаны номерами (Set-of-Mark).
В ответ она присылает одно действие:

```json
{"thought": "Включён тёмный режим, а нужен светлый — нажму на него", "action": "tap", "id": 4}
```

| Слой | Файл | Что делает |
|---|---|---|
| Устройство | [`agent/device.py`](agent/device.py) | Один интерфейс, два варианта: `AdbDevice` (с ПК по USB) и `RootDevice` (на телефоне через `su`) |
| Восприятие | [`agent/perception.py`](agent/perception.py) | `uiautomator dump` → короткий пронумерованный список; скриншот → уменьшенный JPEG с теми же номерами |
| Мозг | [`agent/brain.py`](agent/brain.py) | DeepSeek через OpenAI-совместимый API, одно JSON-действие на шаг |
| Безопасность | [`agent/safety.py`](agent/safety.py) | Нажатия на «Отправить / Оплатить / Удалить…» подтверждает человек; банки и кошельки заблокированы |
| Цикл | [`agent/loop.py`](agent/loop.py) | смотрит → решает → действует; замечает, если экран не изменился; пишет лог каждого шага |

Каждый запуск сохраняется в `logs/`: исходные скриншоты, дерево UI, то, что видела модель, и её ответы.
Это одновременно материал для видео и датасет «экран → действие», на котором потом будем учить маленькую локальную модель.

## Бенчмарк: учится ли агент на своём опыте?

30 задач: переключатели настроек, будильники, калькулятор, контакты, браузер, вопросы о телефоне и несколько
составных. Перед каждой задачей телефон приводится в одно и то же исходное состояние, а успех **проверяется по
реальному состоянию системы** (`settings get`, `dumpsys alarm`, `content query`…), а не по словам агента.
Каждый эксперимент прогоняет все задачи 3 раунда: с памятью-навыками и контрольный — без неё.

![Кривая обучения](docs/img/learning_curve_ru.svg)

| Раунды 2–3 (у памяти уже есть опыт) | С памятью | Без памяти |
|---|---|---|
| **Вызовов модели на задачу** | **5,3** | 7,6 |
| Стоимость 60 задач | **$0,147** | $0,171 |
| Успех | 58/60 | 57/60 |
| Время на задачу | 52 с | 51 с |

**Как устроена память.** Удачный и проверенный запуск сохраняется как человекочитаемый навык
(`open_app settings → tap «Экран» → tap «Тёмная тема»`). Когда приходит ровно та же задача, агент **проходит
знакомый путь сам, находя кнопки по подписям, — без вызовов модели**. Последний, решающий шаг остаётся за моделью:
состояние могло быть другим (слепой повтор «включи Bluetooth» при уже включённом выключил бы его). Для похожих задач
навык идёт в промпт подсказкой.

Что выяснили:
- **Повтор навыков сокращает вызовы модели на 30%, а стоимость — на 14%, без потери в успехе.** Где повтор сработал,
  успешны 51 из 51 задачи. Больше всего выигрыш на длинных задачах: «посчитай 3 + 4 и поставь будильник на столько же
  часов» — 2 вызова модели вместо 16 и 47 с вместо 101 с.
- **Время почти не изменилось** — узкое место не модель. Чтение экрана (`uiautomator dump`) занимает ~2,3 с на шаг,
  думает модель или нет.
- **Первая версия памяти — только подсказки в промпте — не дала ничего** (7,7 шага в обоих случаях, а с памятью даже
  чуть дороже из-за длинного промпта). Разбор вскрыл два бага в самом бенчмарке и один в инструменте ввода текста;
  всё исправлено. Подробности — в [devlog](docs/devlog.md).
- Одна честная ошибка осталась: «верни стандартный размер шрифта». На Android 16 у ползунка 7 делений, стандартное —
  второе, а агент рассуждает по-человечески «стандартный = посередине» и уверенно отчитывается об успехе.

Полный раунд из 30 задач на `deepseek-flash` стоит около **$0,06–0,10**.

## Быстрый старт

Нужны Python 3.10+, [adb](https://developer.android.com/tools/releases/platform-tools), Android-телефон с включённой
отладкой по USB и [ключ DeepSeek API](https://platform.deepseek.com/).

> ⚠️ Берите запасной телефон с тестовым аккаунтом: скриншоты уходят в DeepSeek API.

```bash
git clone https://github.com/shyqzax/LemonadeAgent.git
cd LemonadeAgent
python -m venv .venv
.venv\Scripts\activate           # Windows; на macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env             # и впишите в .env свой ключ DeepSeek
python scripts/doctor.py         # проверит телефон, ключ и scrcpy
python -m interfaces.cli "включи тёмную тему"
```

Параметры: `--mode both|tree|screen` (что видит модель), `--max-steps N`, `--serial SERIAL`. Остановить в любой момент — `Ctrl+C`.

Бенчмарк (с ПК по adb; с `--root` — прямо на телефоне):

```bash
python -m bench.run_bench --rounds 3 --memory --name memory
python -m bench.run_bench --rounds 3 --name baseline
python scripts/plot_bench.py memory baseline     # → docs/img/learning_curve_ru.svg
```

Для ввода кириллицы нужна [ADBKeyBoard](https://github.com/senzhk/ADBKeyBoard) (APK ставится через `adb install`).
Агент включает её только на время ввода и потом возвращает вашу клавиатуру.

## Безопасность

- Запасной телефон с отдельным Google-аккаунтом: ни банков, ни основных мессенджеров.
- Нажатия на кнопки вроде «Отправить», «Оплатить», «Удалить» подтверждает человек.
- Банковские приложения, кошельки и криптобиржи заблокированы.
- Лимит шагов и `Ctrl+C` как аварийная остановка.
- В промпте сказано, что текст на экране — это данные, а не команды. Насколько это работает, измерим на этапе 6.
